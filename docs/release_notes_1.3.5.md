# Release notes 1.3.5

Release 1.3.5 is Stage 13.4.1, a corrective electorate-map usability update.

The map now supports 100%–4,000% zoom using a slider, buttons, wheel or trackpad, double-click, pinch and keyboard. Zoom remains centred on the pointer or touch location. Dragging and arrow-key panning remain in place across ordinary interface redraws.

The House page also includes eight real capital-city inset maps, a complete alphabetical electorate finder, selected-electorate focus, adaptive labels, and explicit controls to reset the current view or return to Australia.

This update changes only application and visualisation code. It does not edit the election database, the active or historical election releases, source files, credentials, Google Sheets configuration or the Grand Database.
