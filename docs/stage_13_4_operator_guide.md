# Stage 13.4 operator guide

Start Politica and open `http://127.0.0.1:8765/results/`.

## Use House analysis

1. Choose **Analysis** in the top navigation.
2. Use the existing State, Party or search boxes to narrow every analysis on the page.
3. Select any electorate in the pendulum, closest-contest or swing ranking to open its full House result.
4. Clear the filters to return to the national result.

The swing chart is the AEC-reported TCP swing for the winning candidate. It is not a newly calculated comparison with redistributed historical boundaries.

## Enlarge city electorates on the map

1. Choose **House**.
2. In **Map view**, choose Australia, a state, or one of the eight capital-city close-ups.
3. Use **+** and **−**, or the mouse wheel or trackpad, to zoom further.
4. Drag the map to move around it.
5. Choose **Reset** to return to the selected national, state or city view.
6. Select an electorate to open its result.

Keyboard users can focus the map and press **+**, **−** or **0**. Individual electorate shapes remain selectable with Tab followed by Enter or Space.

## Static website

The installer builds a new verified static website package automatically. In the operator, choose **Website publication** to preview it or download its ZIP. Nothing is uploaded automatically.
