# Stage 13.3 operator guide

Start Politica and open `http://127.0.0.1:8765/results/`, then choose **House**.

## Use the map

1. Leave the map selector on **Australia** to see all 150 electorates, or choose a state or territory to enlarge that jurisdiction.
2. Point to an electorate to see its name, declared party, member and winning margin.
3. Select an electorate to update the result panel and open its detailed result card.
4. You can also use Tab to focus a division and Enter or Space to select it.
5. Use the existing search box to find an electorate by name; the matching map division and card remain synchronised.

## Verify the source

Choose **Sources** to see the AEC boundary date, feature count, contract checksum and GeoJSON checksum. The source panel also provides the governed GeoJSON, attribution notice and AEC source page.

## Publish the static website

The installer builds a new verified static website package automatically. In the operator, choose **Website publication** to preview it or download its ZIP. Nothing is uploaded automatically.
