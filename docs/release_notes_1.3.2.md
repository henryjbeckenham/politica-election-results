# Release notes 1.3.2

Release 1.3.2 is Stage 13.2: electorate results.

## Added

- Searchable result cards for all 150 declared House electorates.
- A full electorate panel with declared member, party and TCP winning margin.
- Separate TCP and TPP result bars.
- An expandable primary-vote section containing every reported candidate.
- Enrolment, formal votes, informal votes, votes counted, turnout and informality metadata.
- Evidence-based Retained and Gained labels using governed candidate incumbency. When no incumbent contested, the interface says New member rather than guessing the previous party.
