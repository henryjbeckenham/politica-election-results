# Release notes 1.3.3

Release 1.3.3 is Stage 13.3: interactive electorate map.

## Added

- An interactive national map of all 150 House electorates.
- State and territory map views for easier selection of small metropolitan divisions.
- Party-coloured electorate boundaries linked to each declared seat result.
- Hover, focus and selected-seat detail with declared member, party and margin.
- Keyboard operation using Tab plus Enter or Space.
- Direct synchronisation between the map, state selector, search and detailed electorate card.
- An official-source record for the AEC March 2025 boundary archive, all component checksums, the derived GeoJSON checksum and AEC attribution/licence links.
- Boundary assets inside both the local application and the verified host-ready static website ZIP.
