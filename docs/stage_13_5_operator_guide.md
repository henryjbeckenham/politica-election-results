# Stage 13.5 operator guide

Start Politica and open `http://127.0.0.1:8765/results/`, then choose **Senate**.

1. Select a state or territory from a delegation card or the state tabs.
2. Review group first preferences and quota multiples.
3. In **Senate count centre**, use **Previous**, **Next**, the count slider, or **Play**.
4. Change the playback speed if required.
5. Inspect candidate totals against the quota, reported movements, election and exclusion milestones, and declared election order.

The detailed count may take a moment to load when the Senate page is first opened because it contains every official candidate total across every count. Nothing on this page edits the database.
