# Stage 13.4.1 map guide

Open **House**, then scroll to **2025 electorate map**.

- Use **Find electorate** to jump directly to any of the 150 divisions.
- Select a capital-city miniature map to open that metropolitan area.
- Use the zoom slider for precise zoom up to 4,000%.
- A mouse wheel, trackpad, double-click or two-finger pinch also zooms the map.
- Drag the map to move around; keyboard users can use the arrow keys.
- Select a division to centre it and open the result summary.
- Use **Enlarge on map** to return to that division after moving the map.
- Use **Reset view** to reset the current Australia, state or city view.
- Use **Back to Australia** to return to the national map.

The map is read-only and uses the governed AEC boundary geometry bundled with the active publication release.
