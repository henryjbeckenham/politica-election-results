# Stage 13.3 v1.3.3 update

Run `install_stage13_3.command` from the extracted update folder. The installer accepts Stage 13.2 or a repeat Stage 13.3 installation, creates a Desktop backup, installs the interactive electorate map, runs the complete Stage 4–13.3 regression suite, validates the unchanged election release and builds a new host-ready static website ZIP.

Nothing is uploaded or externally deployed.
