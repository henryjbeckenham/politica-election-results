# Stage 13.2 v1.3.2 update

Run `install_stage13_2.command` from the extracted update folder. The installer accepts Stage 13.1 or a repeat Stage 13.2 installation, creates a Desktop backup, installs the electorate-result interface, runs the complete Stage 4–13.2 regression suite, validates the unchanged election release and builds a new host-ready static website ZIP.

Nothing is uploaded or externally deployed.
