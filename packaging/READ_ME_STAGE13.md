# Stage 13.0 package

Use the `install_stage13.command` file at the top of the extracted update folder. The installer accepts an existing application 1.2.0 installation, creates a Desktop backup, installs application 1.3.0, runs the complete Stage 4–13 regression suite, validates the unchanged active election release and builds a new verified static website package.

Node.js is not required on the operator's Mac. The tested Observable site is already compiled in `src/politica_erd/app/results`.
