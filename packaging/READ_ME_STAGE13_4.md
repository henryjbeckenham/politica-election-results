# Stage 13.4 v1.3.4 update

Run `install_stage13_4.command` from the extracted update folder. The installer accepts Stage 13.3 or a repeat Stage 13.4 installation, creates a Desktop backup, installs the House analysis page and map navigation improvements, runs the complete Stage 4–13.4 regression suite, validates the unchanged election release and builds a new host-ready static website ZIP.

Nothing is uploaded or externally deployed.
